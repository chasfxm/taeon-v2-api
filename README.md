# TAEON V2 WEB API

태온종합건설 TAEON V2 웹 업무포털용 Render API.

## Web
https://taeon-v2.onrender.com

## API 예정
https://taeon-v2-api.onrender.com

## Endpoints

GET /api/health

POST /api/intake/text

POST /api/expense/apply

GET /api/pages/history

POST /api/pages/history

## 주의

이 저장소는 Render 배포용 API V1입니다.

기존 로컬 개발본:

D:\5_TAEON_V2

기존 문서엔진:

D:\1_ENGINE_DOCUMENT

기존 이벤트엔진:

D:\2_ENGINE_EVENT

위 로컬 엔진들은 이 Render V1에서 직접 사용하지 않습니다.

Render V1은 웹과 API 연결 및 기본 업무 흐름 검증용입니다.
